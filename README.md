## Perfil

Desarrollo software para la web y el escritorio, conectando interfaces, lógica de negocio, APIs y automatización. Trabajo con distintas tecnologías y elijo las herramientas según las necesidades de cada proyecto.

Mi enfoque abarca la solución completa: una arquitectura clara, una experiencia de uso cuidada y componentes que puedan mantenerse y evolucionar. Las herramientas de inteligencia artificial forman parte de mi trabajo para explorar soluciones, apoyar el desarrollo y automatizar tareas, con criterio técnico sobre el resultado.

## Trabajo seleccionado

### NVBooster

Herramienta nativa para Windows desarrollada con C#, .NET y WPF. Combina una interfaz personalizada, arquitectura MVVM e interacción con servicios y APIs del sistema.

### X78 Architecture

Plataforma web con backend en Node.js y un panel de administración desacoplado, organizada en componentes de cliente y servidor.

### BOTP Core

Aplicación de automatización en Python con interfaz Tkinter, orientada a coordinar flujos de trabajo y procesamiento de datos.

### qrGPT

Aplicación web construida con Next.js, React y Radix UI, con una interfaz basada en componentes.

Este perfil presenta una selección de proyectos y las tecnologías utilizadas, sin publicar su código fuente.

## Forma de trabajar

- Entender el problema antes de elegir la tecnología.
- Conectar frontend, backend y herramientas de sistema cuando la solución lo requiere.
- Priorizar claridad, mantenibilidad y una experiencia de uso coherente.
- Integrar automatización e IA donde aporten valor al trabajo.
