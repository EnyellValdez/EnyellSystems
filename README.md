### 🏆 Portfolio de Proyectos y Desarrollos

> *Una muestra de mi capacidad multiplataforma, abarcando desde optimización de hardware hasta plataformas web empresariales y herramientas multimedia.*

#### ⚡ Sistemas y Software Nativos
- **NVBooster:** Herramienta avanzada nativa para Windows en `C#` / `.NET WPF`. Manipula servicios del sistema y prioridades de CPU para maximizar rendimiento de GPU y reducir latencia.
- **Enyell Forense:** Herramienta modular de escaneo de sistemas locales y seguridad, escrita combinando la potencia de `C++` y `Python`.
- **Scripts de Utilidad del Sistema:** Herramientas de automatización para codificación de video, escalado de resoluciones y procesamiento de archivos vía `Windows PowerShell`, `Batch Scripting` y parámetros de `FFmpeg`.
- **Enyell-Lyrics:** Script en `Python` para la terminal que reproduce letras sincronizadas exactamente con las pistas de audio.

#### 🌐 Plataformas Web, PWA y Full-Stack
- **QR.Enyell:** Aplicación web full-stack para la creación y administración de códigos QR dinámicos.
- **LinkHub:** Aplicación Web Progresiva (PWA) para gestión de enlaces, integrada con base de datos en `Firebase`.
- **BarberTime:** Aplicación web (PWA) diseñada para la reserva y gestión integral de citas de barbería.
- **Préstamos Pro:** Sistema de control y seguimiento financiero de préstamos con almacenamiento en `Firebase`.
- **X78 Architecture:** Plataforma web con panel de administración desacoplado, estructurado de forma modular y escalable.
- **Control Maestro:** Dashboard de administración web multi-usuario (desarrollado en colaboración con JuniorStream).
- **CV Interactivo:** Página web personal de currículum estructurada con `HTML/CSS` con función de exportación a formato PDF.

#### 🎮 Gaming, Bots y Multimedia
- **EL CUARTEL GAMING:** Bot de Discord programado en `Python`, conectado a un panel de control web alojado en `Netlify` y sincronizado con `Firebase` para gestionar un sistema de ranking de usuarios automatizado.
- **AimMaster by Enyell:** Utilidad web responsiva para configurar interfaces y sensibilidad en videojuegos, desarrollada en colaboración con RDClaxxar (incluye lógicas avanzadas de temporizadores en `JavaScript`).
- **BonusPlay:** Aplicación web interactiva con mecánicas de estilo arcade.
- **Catálogo Perfumes EV:** Mantenimiento de sitio web e-commerce, estructuración de descripciones y creación de material promocional.
- **Assets de ENYELL TV / Enyell Studios:** Producción de intros animadas, recursos visuales de branding (`Photoshop`, `After Effects`) y producción de pistas musicales originales de dembow/trap para soundtracks de gaming.
